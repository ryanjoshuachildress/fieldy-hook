A JS function receiving (event, raw). event holds the normalized fields (id, received_at, event_date, transcript, speaker, event_type, conversation_id); raw is the parsed original payload. Example: (event, raw) => ({ day: event.event_date?.slice(0, 10), words: (event.transcript || '').split(/\s+/).length })
